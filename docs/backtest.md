# 最小回测

单票、多头、双均线。用来验证成交规则，不是用来选策略。

## 规则

1. **信号**：用前复权收盘价算 SMA。快线在 T 日收盘高于慢线则目标为多，否则为空。当天收盘才知道信号，当天开盘不能用。
2. **成交**：目标仓位在 **下一根未复权开盘价** 执行。买入价 = 开盘 × (1+滑点)，卖出价 = 开盘 × (1−滑点)。
3. **T+1**：买入当日不能卖。本策略信号在收盘产生，通常最早次日卖，这条主要防止以后换成别的规则时同日买卖。
4. **涨跌停 / 停牌**：涨停或开盘触及涨停价不买；跌停或开盘触及跌停价不卖；停牌买卖都不成交。当天不成交则继续持有原仓，下一交易日再试。
5. **现金与整手**：买入股数是 100 的倍数，且 成交额+佣金 ≤ 现金。买不起就空仓。卖出一次性清仓。
6. **费用**：佣金按成交额 × 费率，不足最低额按最低额；印花税只在卖出时记。默认万分之 2.5 佣金、最低 5 元、卖出万分之 5 印花税、滑点 0.1%。
7. **净值**：每日现金 + 持股 × **未复权收盘**。买入持有对照用同期 **前复权收盘**。

均线预热：若指定了开始日期，会再往前多取约 `slow×3+20` 个自然日的 K 线，只在开始日期之后成交。

## 怎么跑

```powershell
go run ./cmd/ashare backtest 000001.SZ -start 20260101 -end 20261013
go run ./cmd/ashare backtest 000001.SZ -fast 5 -slow 20 -cash 100000 -out reports/000001.json
```

页面：数据看板 →「最小回测」。API：`POST /api/backtest`。

同一库、同一参数应得到同一结果。费用默认值在 `config.yaml` 的 `backtest` 段。
